# John Spurgeon - Portfolio

A modern, responsive portfolio website built with Next.js, showcasing John Spurgeon's work as a Full Stack Developer.

## 🚀 Features

- **Responsive Design**: Optimized for all device sizes
- **Modern Tech Stack**: Built with Next.js, React, TypeScript, and Tailwind CSS
- **Smooth Animations**: GSAP animations and Lenis smooth scrolling
- **Project Showcase**: Interactive project gallery with detailed case studies
- **Contact Integration**: Easy contact form and social media links

## 🛠️ Tech Stack

- **Frontend**: React, Next.js, TypeScript
- **Styling**: Tailwind CSS
- **Animations**: GSAP, Framer Motion
- **Fonts**: Google Fonts (Anton, Roboto Flex)
- **Smooth Scrolling**: Lenis

## 🏃‍♂️ Getting Started

1. **Install Dependencies**
   ```bash
   npm install
   # or
   pnpm install
   ```

2. **Run Development Server**
   ```bash
   npm run dev
   # or
   pnpm dev
   ```

3. **Open Browser**
   Navigate to [http://localhost:3000](http://localhost:3000)

## 📝 Customization

To further customize this portfolio:

1. **Update Personal Info**: Edit `lib/data.ts`
2. **Add Projects**: Update the `PROJECTS` array in `lib/data.ts`
3. **Change Experience**: Modify `MY_EXPERIENCE` in `lib/data.ts`
4. **Update Skills**: Edit `MY_STACK` in `lib/data.ts`
5. **Add Analytics**: Uncomment and update GA/Hotjar IDs in `app/layout.tsx`
